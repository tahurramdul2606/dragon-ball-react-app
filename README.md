# 🐉 Dragon Ball Character App

A responsive React application that allows users to explore Dragon Ball characters, filter them by race, view detailed information, and manage their favorite characters.

---

## 🚀 Features

* 🔐 User Authentication (Register & Login)
* 👤 Profile Management (Edit user details)
* 📊 Dashboard with character stats
* 🔍 Filter characters by race
* 📄 View detailed character information
* ❤️ Add/Remove favorites
* 📱 Fully responsive (Tailwind CSS)
* 🔄 Pagination support

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Routing:** React Router DOM
* **Styling:** Tailwind CSS
* **State Management:** React Hooks (`useState`, `useEffect`, `useNavigate`, `useParams`)
* **Website:** https://web.dragonball-api.com/
* **API:** https://dragonball-api.com/api/characters

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/your-username/dragonball-app.git
```

2. Navigate into the project:

```bash
cd dragonball-app
```

3. Install dependencies:

```bash
npm install
```

4. Run the app:

```bash
npm run dev
```

## ⚠️ Limitations

* No backend (data stored in local state)
* Data resets on page refresh
* No authentication persistence
